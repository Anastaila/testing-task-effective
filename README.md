## Репозиторий для автотестов страницы ReportPortal
__Реализованные тесты:__ позитивный тест на логин, негативный тест на логин и тест на создание виджета
__Стек технологий:__ testng 7.8.0, java 17.0.13, allure-report, maven

__Как запустить тесты?__
1.Зайти в папку портал
2. Открыть папку в IDE (к примеру Visual studio code)
3. Убедиться, что предварительно установлены Java, Maven 
4. Запустить тесты с помощью команды:
`mvn clean test`
5. Запустить генерацию отчёта с помощью команды:
`allure serve target/allure-results`
